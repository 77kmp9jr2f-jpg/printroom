Deployment & scale

Up to 64 saved printers, eight concurrent printer polls, and four visible camera connections per dashboard. Two physical K2 Plus printers are qualified here; larger fleets need testing on their own host and network. Offline printers can increase refresh time; source ages remain visible.

Use private IPv4 addresses reachable from the service. DNS names, IPv6, HTTPS printer endpoints and reverse-proxy path prefixes are not supported yet. Subnet discovery does not cross unrouted VLANs or rely on mDNS. Generic cameras require a named stream in go2rtc.

CFSync has its own printer configuration. Adding or changing a printer here updates monitoring and camera routing; configure that printer separately in CFSync before using its spool links.

Printer profiles are saved in the persistent data volume. Printer and Spoolman connections are managed here. The bootstrap file still configures LAN access and control policy. Back up the data volume; saved API keys must be protected like other host secrets.
